# Mein Netzwerk-Optimierer

Kostenlose Android-App zur Anzeige von WLAN-Signal, Frequenz und sichtbarer Kanalbelegung. Die App verändert keine Routereinstellungen. Android kann WLAN-Scans zeitlich begrenzen.

## APK bauen
GitHub → Actions → Android APK erstellen → Run workflow. Nach erfolgreichem Build das Artefakt **Mein-Netzwerk-Optimierer-APK** herunterladen, ZIP entpacken und APK auf Android installieren.

Hinweis: Für die WLAN-Umgebungssuche sind Standortberechtigung und aktivierte Standortdienste erforderlich. Keine Daten werden an einen Server gesendet.
